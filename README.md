## 🧭 Purpose

Central home for **all visual identity assets** used across OpenGrantStack websites, apps, documentation, and presentations.

| Asset Type | Description |
|------------|-------------|
| **Logos** | Primary mark, wordmark, monochrome, and inverse versions |
| **Color System** | Primary, secondary, semantic, and accessibility-safe palettes |
| **Icons** | Product and status icons aligned with the design system |
| **Templates** | Social cards, presentation decks, README headers |
| **Guidelines** | Usage rules, clear space, do’s and don’ts |

---

## 🎨 Suggested color direction

| Role | Suggested | Notes |
|------|-----------|-------|
| Primary | Deep indigo / violet | Trust + governance |
| Accent | Cyan / teal | Clarity + openness |
| Success | Green | Audit-ready / complete |
| Warning | Amber | Attention |
| Neutral | Slate / gray scale | Text and surfaces |

Exact values will live in `colors/` once finalized.

## 📁 Planned structure

```text
brand-assets/
├── logos/              # SVG + PNG variants
├── colors/             # Palette definitions (JSON / CSS / Tailwind)
├── icons/              # Icon set
├── templates/          # Social, slides, headers
├── guidelines/         # Brand book / usage rules
├── docs/
├── LICENSE
└── README.md
```
